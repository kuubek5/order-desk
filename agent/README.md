# KMill Machine Agent

Крихітний view-only HTTP-сервер для ПК фрезерного верстата (RemiCORE /
imes-icore). KMill CRM **сам ходить** до нього по кадр екрана (PULL — бо CRM
слухає лише `127.0.0.1` і тягнеться до машини по LAN, як робить це VNC), і
розпізнає з кадру потрібне (прогрес %, час, шпиндель, назву `.iso`).

**Чому так, а не «агент пушить у CRM»:** CRM прив'язаний до loopback заради
безпеки — назовні не слухає. Тому машину опитує CRM, а агент лише віддає кадр
на запит. Ідеально: майже нульове навантаження в спокої (працює тільки коли
його опитують), нічого не «дзвонить додому» саме собою.

## Режими запуску

| Команда | Що робить |
|---|---|
| `kmill-agent.exe` (подвійний клік) | відкриває **меню налаштувань** у браузері |
| `kmill-agent.exe -setup` | те саме — меню налаштувань |
| `kmill-agent.exe -serve` | фоновий сервер кадру (його запускає автозадача) |

**Меню налаштувань** (локальна сторінка `http://127.0.0.1:8766`): вписуєш назву
верстата, токен (кнопка «Новий» = випадковий), монітор і порт; бачиш IP цього
ПК і **готову адресу для CRM**, стан автозапуску, живий кадр екрана. Кнопка
«Зберегти й запустити» пише `agent.json`, реєструє автозапуск (Task Scheduler)
і додає правило брандмауера. Якщо запущено без прав адміністратора — меню саме
перепитає їх через UAC.

## Ендпоінти сервера (v1)

| Метод | Відповідь | Авторизація |
|---|---|---|
| `GET /healthz` | `ok` | нема (лише живість) |
| `GET /status` | JSON `{name,hostname,displays,version,time}` | токен |
| `GET /capture?display=N` | `image/png` (кадр дисплея) | токен |

Токен — заголовок `X-Agent-Token: <token>` або `?token=<token>`.

Кроп потрібної зони (смуга %, час) робить **CRM** зі свого боку — агент віддає
повний кадр, лишаючись максимально простим. Нові потреби (індекс дисплея,
пізніше — кроп-прямокутник чи структуровані UIA-поля) додаються параметром
запиту / ключем конфігу, **без переустановлення** на верстатах.

## Збірка

Локально Go не потрібен — exe збирає CI (`.github/workflows/agent-build.yml`,
**Go 1.20** — остання версія з підтримкою Windows 7/8). Артефакт
`kmill-agent.exe` качається зі сторінки Actions.

Вручну (з Go 1.20+):

```
cd agent
go mod tidy
GOOS=windows GOARCH=amd64 go build -ldflags "-s -w -H=windowsgui -X main.Version=0.1.0" -o kmill-agent.exe .
```

`-H=windowsgui` ховає консоль (агент працює тихо; логи — у `kmill-agent.log`
поряд з exe). Один статичний .exe, без cgo → крос-компілюється з будь-якої ОС.

## Встановлення на верстат (просто)

1. Запустити **`KMillAgent-Setup-X.Y.Z.exe`** (зі сторінки Actions, джоб
   `installer`) — ставить агента й одразу відкриває **меню налаштувань**.
2. У меню: вписати назву, натиснути «Новий» для токена, вибрати монітор → 
   **«Зберегти й запустити»**. Автозапуск і брандмауер налаштуються самі.
3. Скопіювати з меню **адресу** (`http://<IP>:8765`) і **токен**.
4. У KMill: Налаштування → Верстати → додати машину з цією адресою й токеном.

Пізніше змінити налаштування: меню Пуск → «KMill Agent — налаштування».

### Ручний спосіб (без інсталятора)

1. Скопіювати `kmill-agent.exe` + `agent.json` у, напр., `C:\KMillAgent\`.
2. Подвійний клік по exe → меню налаштувань, заповнити й зберегти. Або вписати
   `token`/`name` у `agent.json` руками й запустити `install.ps1` (від адміна).

Перевірка вручну з ПК CRM:
```
curl -H "X-Agent-Token: <token>" http://<IP-верстата>:8765/status
```

## Безпека

- Токен обов'язковий на `/status` і `/capture`, звіряється constant-time.
- Мережа лаби довірена; за бажанням — обмежити брандмауером порт `8765` лише
  для IP ПК з CRM.
- Агент **тільки читає екран** і віддає кадр; нічого не запускає й не змінює
  на верстаті.
