{# Живий сегмент «таблиця:» у верхньому рядку черги (topbar-live). Оновлює САМ СЕБЕ кожні 3с через GET /sheets/state — інакше topbar оновлюється лише при повному завантаженні сторінки, і «синхронізує…» було б невидиме (а «✓ щойно» лишалося б застарілим, поки синк ще біжить). hx-swap="outerHTML" на обгортці: роут повертає її знову з тим самим поллом. Обгортка display:contents (css) — у flex-рядку лишається сам сегмент. Стани (пріоритет): running (пульсує «синхронізує…») → paused («на паузі») → звичайний ярлик стану (sync_status.sheet.label, напр. «✓ щойно»). #} {# Стан беремо з контексту роуту, а якщо його немає — з Jinja-глобала (deps.sync_state). Так один і той самий партіал живе і в шапці Черги, і в рейці на КОЖНОМУ екрані: пауза синку більше не видима лише з Черги (аудит 05.09.26, UX 1.8). #} {% from "_sync_dot.html" import sync_dot %} {%- set _st = sync_status if sync_status is defined and sync_status else sync_state() -%} {%- if _st %} {%- set s = _st.sheet -%} {%- if s.running %}таблиця: синхронізує… {%- elif s.paused %}таблиця: на паузі {%- else %}таблиця: {{ s.label }}{% endif %} {# Кружок здоровʼя синку в рейці оновлюється РАЗОМ із цим поллом (hx-swap-oob), а не власним запитом: полл і так ходить кожні 3 с, а два джерела правди розійшлися б — підпис писав би «помилка», кружок світив би зеленим із моменту завантаження сторінки. `oob_dot` ставить ЛИШЕ роут /sheets/state і лише адміну: у оператора пункт меню з цим id не рендериться, і htmx лаявся б у консоль на ненайдену ціль. #} {%- if oob_dot is defined and oob_dot %}{{ sync_dot(_st, oob=true) }}{% endif %} {%- endif %}
