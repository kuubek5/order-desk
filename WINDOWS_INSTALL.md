# KuubMill — standalone Windows

Основний production-сценарій: один робочий комп’ютер Windows 10/11 x64, без
Docker і без зовнішнього сервера. KuubMill запускає локальний вебінтерфейс
на `http://127.0.0.1:8000`; порт не відкривається в локальну мережу чи Інтернет.

## Що зберігається локально

Дані поточного Windows-користувача лежать у `%LOCALAPPDATA%\KuubMill`:

- `order_desk.db` — замовлення, історія, користувачі та поштовий тріаж;
- `mail_attachments\` — тимчасові вкладення листів;
- `master.key` — DPAPI-захищений ключ секретних налаштувань;
- `logs\` — ротаційні технічні логи;
- `backups\` — останні п’ять backup БД перед міграціями.

Бінарні файли встановлюються окремо в
`%LOCALAPPDATA%\Programs\KuubMill` і можуть оновлюватись без видалення даних.
Uninstaller навмисно не видаляє робочу базу та вкладення.

`master.key` захищений Windows DPAPI для облікового запису, який встановив і
запускає програму. Інший Windows-користувач не зможе його використати.

## Безпека робочого ПК

SQLite та CAD-вкладення не мають власного повнодискового шифрування. Перед
роботою з реальними даними потрібно:

1. Увімкнути BitLocker на системному диску.
2. Використовувати Windows-акаунт із паролем/PIN і автоматичним блокуванням.
3. Не давати іншим працівникам доступ до цього Windows-профілю.
4. Не синхронізувати `%LOCALAPPDATA%\KuubMill` у публічну хмару.
5. Для папок техніків використовувати абсолютний локальний або UNC-шлях;
   mapped drives можуть бути недоступні при іншому способі автозапуску.

Google Sheets та ukr.net, звісно, потребують Інтернету, але сам застосунок і
база не приймають зовнішніх підключень.

## Перший запуск

1. Встановити `KuubMill-Setup-*.exe` під тим Windows-користувачем, який буде
   працювати з програмою.
2. Залишити ввімкненим автозапуск при вході в Windows.
3. Після запуску браузер відкриє локальну сторінку створення першого
   адміністратора. Стандартного пароля немає.
4. У «Налаштуваннях» ввести Google Sheet ID, service-account JSON, IMAP логін і
   пароль для програм, а також абсолютні шляхи `export` і папки техніків.

## Збірка інсталятора

На build-комп’ютері потрібні Python 3.11 x64 та Inno Setup 6.

```powershell
.\build_windows.ps1
```

Скрипт створює PyInstaller onedir build у `dist\KuubMill`. Потім відкрити
`installer\KuubMill.iss` в Inno Setup і натиснути Compile. Готовий інсталятор
з’явиться у `dist-installer`.

Onedir обрано свідомо: він швидше стартує, не розпаковує застосунок у temp при
кожному запуску й зазвичай створює менше проблем з антивірусом, ніж onefile.

## Оновлення і відновлення

Перед реальною інсталяцією нової версії потрібно зберігати копію всього
`%LOCALAPPDATA%\KuubMill`. Launcher додатково робить backup SQLite перед
міграціями й зберігає п’ять останніх копій.

DPAPI `master.key` прив’язаний до Windows-профілю. Просте копіювання каталогу на
інший ПК зараз **не підтримується**: старі зашифровані налаштування неможливо
відкрити іншим Windows-профілем. Recovery/export workflow потрібно реалізувати
і перевірити до фінального production-релізу; до цього backup призначений для
відновлення в тому самому Windows-профілі/на тому самому ПК.
